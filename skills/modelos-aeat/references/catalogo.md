# Catalogo de modelos

Mapa para identificar **que modelo corresponde**. Los plazos son los ordinarios; verifica
el calendario del contribuyente del ejercicio, que tiene adaptaciones anuales.

## Arbol de decision

```
PERSONA FISICA residente
  sin actividad        → 100  (+714 si patrimonio)
  con actividad        → 100 + 130/131 + 303/390 + 111/115 + 347/349
PERSONA JURIDICA       → 200 + 202 + 303/390 + 111/115/123 + 347/349 + 232
NO RESIDENTE  sin EP   → 210   |  con EP → 200 + 206
ENTIDAD EN ATRIBUCION  → 184 + IVA y retenciones

OPERACION
  compra inmueble a particular → 600 (TPO)
  compra a promotor            → IVA + 600 (AJD)
  herencia                     → 650 + plusvalia municipal
  donacion                     → 651 + IRPF DEL DONANTE
  bienes a la UE               → 303 + 349 + Intrastat (si umbral)
  servicios a empresa UE       → 303 + 349, SIN Intrastat
  exportacion fuera UE         → 303 + DUA, sin 349 ni Intrastat
```

> **Intrastat cubre bienes; el 349 cubre bienes y servicios.** No son equivalentes.

## 14. Cómo elegir el modelo — árbol rápido

```
¿Quién? ─ Persona física residente ─ ¿Actividad económica?
│                                     ├ No  → 100 (+ 714 si procede)
│                                     └ Sí  → 100 + 130/131 + 303/390 + 111/115 + 347/349
├ Persona jurídica residente        → 200 + 202 + 303/390 + 111/115/123 + 347/349 + 232
├ No residente sin EP               → 210 (+ 211 si compra inmueble)
├ No residente con EP               → 200 + 206
└ Entidad en atribución de rentas   → 184 + obligaciones de IVA y retenciones

¿Qué operación? ─ Compra inmueble a particular       → 600 (TPO)
                ├ Compra inmueble a promotor          → IVA + 600 (AJD)
                ├ Herencia                            → 650 + IIVTNU
                ├ Donación                            → 651 + IRPF del donante
                ├ Venta de bienes a la UE             → 303 + 349 + Intrastat (si umbral)
                ├ Compra de bienes en la UE           → 303 (AIB) + 349 + Intrastat
                ├ Servicios a empresa de la UE        → 303 + 349 (sin Intrastat)
                └ Exportación fuera de la UE          → 303 + DUA (sin 349 ni Intrastat)
```

> **Regla**: Intrastat cubre **bienes** entre Estados miembros, nunca servicios; el 349
> cubre bienes **y** servicios intracomunitarios. No son intercambiables ni equivalentes.
